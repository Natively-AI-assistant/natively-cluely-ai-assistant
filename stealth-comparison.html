Natively's Architectural Superiority
All 5 critical stealth defenses verified in Natively's source code
01
Deep OS Binary Masquerade
Competitors like Parakeet and LockedIn rely on the "U+2800 Braille Blank" Unicode trick in CFBundleDisplayName. While this creates a blank line in GUI lists, any proctor inspecting proc_pidpath() or executable basenames sees their brand name immediately. Natively renames the executable and helpers to legitimate system daemons (corespeechd / audiodg.exe) with an authentic Apple bundle ID (com.apple.corespeechd).
Binary Status: Verified clean in HackerEarth v3.1.1 ps -ax -o command= scan.
02
500ms Backstop Protection Loop
Natively applies setContentProtection(true) at window creation, but also runs an idempotent 500ms continuous loop in stealthProtection.ts. This explicitly mitigates Electron #39907 (the Windows 11 race condition where display sleep, DPI scaling, or monitor hot-plugging silently drops SetWindowDisplayAffinity).
Source Citation: electron/utils/stealthProtection.ts:13 (500ms idempotent re-assert).
03
Foreign Window & Tooltip Guard
Electron's setContentProtection only affects BrowserWindow instances. Native tooltips, dialogs, and popups create their own OS-level top-layer windows that leak into screen recordings. Natively's foreignWindowCaptureGuard.ts coordinates with a native Rust module to run a 50ms sweep excluding non-BrowserWindows.
Source Citation: electron/services/foreignWindowCaptureGuard.ts:36 (50ms idle sweep).
04
WDA Windows Build 19041 Gating
On Windows, WDA_EXCLUDEFROMCAPTURE is only supported on Windows 10/11 build ≥ 19041 (20H1). Calling it on older builds defaults or causes black-box rendering (WDA_MONITOR). Natively implements dynamic build inspection to safely select the correct capture mode.
Source Citation: electron/utils/windowsCaptureMode.ts:22 (WINDOWS_EXCLUDE_FROM_CAPTURE_BUILD = 19041).
05
Zero-Egress Network Stealth Gating
Final Round AI, Parakeet, and LockedIn broadcast telemetry, bug reports, and updates during interviews. Final Round even bundles @fingerprint/agent to transmit machine IDs to Corgi Labs. Natively enforces a complete outbound network lock: Sentry sinks, GA4, auto-updaters, model discovery, and calendar polling are terminated in stealth mode.
Binary Status: 0 outbound connections to analytics or third-party sinks.
06
Active Window Title Camouflage
Proctors scan window names via native OS APIs (CGWindowListCopyWindowInfo on macOS and EnumWindows on Windows). Final Round emits windows titled "Final Round AI" and "Capture Halo", triggering instant substring regex matches. Natively intercepts all 7 application windows, enforcing disguised native utility titles like Activity Monitor and Terminal.
Window Title Status: Disguised as OS native tools; active guard keeps brand out.
Accurate Gap Analysis & Physical Boundaries
The true remaining software opportunities and unmitigated real-world boundaries
Actionable Software Gap From LockedIn AI
1. User-Configurable process.title Whitelisting
Natively hardcodes its disguised process titles (corespeechd/audiodg). If a company or proctor enforces a strict whitelist allowing only approved productivity apps (e.g., slack, chrome, code), Natively cannot adapt on the fly. LockedIn allows users to input any custom whitelist string directly from settings.
Recommended Action: Add a settings key customProcessTitle that writes to process.title via IPC on launch.
Architectural Tradeoff From LockedIn AI
2. Structural LSUIElement Dock Elimination
LockedIn sets LSUIElement: true in its Info.plist, permanently barring the app from ever showing in the Dock or Cmd+Tab switcher. Natively deliberately keeps Dock visibility in normal mode for brand UX and uses a runtime app.dock.hide() loop in stealth mode, which is subject to rare OS reset flickers.
Design Consideration: Offer an optional "Ghost Edition" build flavor with LSUIElement: true hard-baked into Info.plist.
Residual Footprint Electron Default
3. userData Path & Command-Line Argv Trace
Electron initializes user storage under ~/Library/Application Support/Natively or passes --user-data-dir=.../Natively in process.argv. A low-level proctor inspecting full command-line arguments (e.g. /proc/pid/cmdline) can still detect the word "Natively".
Recommended Action: Override app.setPath('userData', ...) to a generic system cache location (e.g. .../CoreSpeechData) during stealth.
Physical Boundary Unmitigated by Software
4. Behavioral Anti-Cheat & Human In-The-Loop
No client-side software disguise can defeat external behavioral analytics:
  • Focus Blur: Clicking the overlay causes the testing window to lose focus (logged by HackerEarth/Micro1).
  • Keystroke Timelines: Test platforms record typing velocity and pauses; pasting solutions triggers algorithmic flags.
  • Human Proctors (Pearson OnVUE): Enforce physical 360° webcam room and taskbar inspections that defeat all software overlays.
Strict Rule: Never attempt software evasion on human-proctored exams (OnVUE). Use keyboard shortcuts only to avoid window blur.
