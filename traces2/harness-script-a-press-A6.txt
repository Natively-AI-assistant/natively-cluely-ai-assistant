--- Raw model answer ---
TinRoof is a pure-Go implementation of the **Raft consensus algorithm** with a built-in **linearizable key-value store**, sitting around **1.4k GitHub stars**. I built it because I wanted a production-grade consensus library that was easy to read and embed, so I focused on a small surface area, clean leader election and log replication, and a simple KV API on top of it. It served me well as a learning exercise in distributed systems and as a reference implementation I've pointed teammates at when explaining how Raft actually behaves under partition and election scenarios.
