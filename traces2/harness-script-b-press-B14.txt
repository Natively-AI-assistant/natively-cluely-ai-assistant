**📝 Worth noting:** The paper itself only demonstrates generalization to English constituency parsing beyond translation. It doesn't make broader claims about how well purely attention-based architectures transfer to other domains, that's left to follow-up work.

So on the question of whether it generalizes well beyond translation: the authors only really stress-test it on constituency parsing, which is encouraging but a narrow sample. The architecture has no recurrence or convolution, so in principle it should be domain-agnostic since attention doesn't care about the structure of the input. In practice, though, position information has to be added back in (sinusoidal embeddings here), and tasks with very different input/output layouts, like image generation or reinforcement learning, would need those position schemes reworked. The paper shows the idea is portable, not that it solves everything.
