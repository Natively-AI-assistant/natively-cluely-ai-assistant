--- Raw model answer ---
Levee is an open-source Go library that acts as an adaptive circuit breaker for RPCs. It tracks per-method error rates and uses an EWMA over recent responses to set the failure threshold dynamically, so it tightens or relaxes based on real traffic rather than a static number. It also exposes half-open probing and per-call callbacks so you can hook it into observability or fall back to a cached response.
